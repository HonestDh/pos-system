# POS System

Point of Sale (POS) system built with React, Webpack, and Tailwind CSS.

## 🚀 Features

- Modern UI with Tailwind CSS
- Fast development with Webpack
- Reusable React components
- Optimized build process

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## 🔧 Installation

npm install
#or
yarn install
## 🏃‍♂️ Development mode
npm start
#or
yarn start
